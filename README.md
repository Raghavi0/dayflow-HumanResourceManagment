# Dayflow – Human Resource Management System

Every workday, perfectly aligned.

Dayflow is a Human Resource Management System (HRMS) designed to digitize and streamline essential HR operations. The system provides separate role-based access for **Employees** and **Admin/HR Officers**, making it easier to manage employee information, attendance, leave requests, payroll details, and approval workflows.

>>> Features

>> Authentication & Authorization

* Employee and Admin/HR registration
* Secure Sign Up and Sign In
* Email verification
* Role-based access control
* Dashboard redirection after successful login

>> Employee Management

* View personal and job details
* View salary structure
* Manage profile information
* Upload/update profile picture
* Manage documents
* Admin can manage employee details

>> Attendance Management

* Daily and weekly attendance tracking
* Employee check-in/check-out
* Attendance status:
* Present
* Absent
* Half-day
* Leave
* Employees can view their own attendance
* Admin/HR can view attendance records of all employees

>> Leave & Time-Off Management

Employees can:

* Apply for leave
* Select leave type:

  * Paid Leave
  * Sick Leave
  * Unpaid Leave
* Select a date range
* Add remarks
* Track request status

Admin/HR can:

* View leave requests
* Approve or reject requests
* Add comments
* Monitor updated leave records

 Payroll & Salary Management

* Employees can view their salary/payroll information
* Admin/HR can view payroll information for employees
* Admin can update salary structures
* Payroll accuracy management
* Salary slip and attendance reports

 Dashboard & Notifications

Employee Dashboard

* Profile
* Attendance
* Leave Requests
* Recent activity/alerts

**Admin/HR Dashboard**

* Employee list
* Attendance records
* Leave approvals
* Employee-wise information
* Reports and analytics

>> User Roles

| Role                   | Responsibilities                                             |
| ---------------------- | ------------------------------------------------------------ |
| **Employee**           | View profile, attendance, salary details and apply for leave |
| **Admin / HR Officer** | Manage employees, attendance, leave approvals and payroll    |

>> Technologies Used

* Frontend: `React.js / HTML / CSS / JavaScript`
* Backend: `Node.js / Express.js`
* Database: `MongoDB / MySQL`
* Authentication: `JWT / Firebase Authentication`
* Version Control: `Git & GitHub`

>> Project Objective

The main objective of Dayflow is to provide a centralized HR platform that reduces manual HR operations and allows employees and HR personnel to efficiently manage everyday workforce activities.

>> Future Enhancements

* Automated payroll processing
* Advanced HR analytics
* Automated email notifications
* Detailed salary-slip generation
* Attendance reports and analytics
* Additional HR management modules
* Mobile application support

>> Problem Statement

Dayflow is based on the requirement to digitize core HR operations including employee onboarding, profile management, attendance tracking, leave management, payroll visibility, and approval workflows for Admin/HR and Employees.
